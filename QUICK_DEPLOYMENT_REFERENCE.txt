┌─────────────────────────────────────────────────────────────────────────────────┐
│ FOR BUILDERS: Create the Installer                                             │
└─────────────────────────────────────────────────────────────────────────────────┘

1. BUILD APPLICATION
   ├─ Visual Studio: Build → Build Solution (Release mode)
   └─ Output: bin\Debug\ (verify all DLLs present)

2. INSTALL INNO SETUP
   ├─ Download: https://jrsoftware.org/isdl.php
   ├─ Install version 6.x
   └─ Verify: C:\Program Files (x86)\Inno Setup 6\ISCC.exe exists

3. BUILD INSTALLER
   ├─ Method A (GUI): Open setup_with_db.iss in Inno Setup, press F9
   ├─ Method B (CLI): ISCC.exe setup_with_db.iss
   └─ Output: Installer\FatimaChurchTBM_Setup_v1.0.1.exe

4. TEST INSTALLER
   ├─ Test on clean Windows VM (no Fatima Church installed)
   ├─ Verify database setup succeeds
   ├─ Check family grid loads in <5 seconds
   └─ Confirm application launches successfully

5. DISTRIBUTE
   ├─ Create release package:
   │  ├─ FatimaChurchTBM_Setup_v1.0.1.exe
   │  ├─ INSTALLATION_GUIDE.md
   │  ├─ SYSTEM_REQUIREMENTS.txt
   │  └─ README.txt
   └─ Compress as ZIP for distribution

┌─────────────────────────────────────────────────────────────────────────────────┐
│ FOR USERS: Install the Application                                             │
└─────────────────────────────────────────────────────────────────────────────────┘

1. PREREQUISITES
   ├─ Windows 7 or later
   ├─ .NET Framework 4.8+
   └─ SQL Server 2016+ or LocalDB

2. RUN INSTALLER
   ├─ Double-click: FatimaChurchTBM_Setup_v1.0.1.exe
   ├─ Click "Yes" for Admin Rights
   └─ Click "Next" at welcome screen

3. ENTER DATABASE SETTINGS
   ├─ SQL Server Instance:
   │  ├─ LocalDB users: (localdb)\MSSQLLocalDB
   │  ├─ Express users: COMPUTERNAME\SQLEXPRESS
   │  └─ Or: your-server-name
   ├─ Database Name: fatimachurchtbm (or custom)
   └─ Click "Next"

4. ENTER CREDENTIALS
   ├─ Username: sa (system admin)
   ├─ Password: (your SQL Server password)
   └─ Click "Next"

5. COMPLETE INSTALLATION
   ├─ Select optional tasks (desktop icon, etc.)
   ├─ Click "Install"
   ├─ Wait for database setup to complete ⏳
   └─ Application launches automatically ✓

6. VERIFY SUCCESS
   ├─ Application window opens
   ├─ Login screen displays
   ├─ Log in with credentials
   ├─ Family grid loads quickly (<5 seconds)
   └─ All systems operational! ✓

┌─────────────────────────────────────────────────────────────────────────────────┐
│ DATABASE SETUP AUTOMATION (Behind the Scenes)                                  │
└─────────────────────────────────────────────────────────────────────────────────┘

When installer reaches "Setting up database..." step:

1. POWERSHELL EXECUTION
   └─ Scripts/DatabaseSetup.ps1 runs with installer-provided credentials

2. CONNECTION TEST
   ├─ Connects to specified SQL Server instance
   ├─ Validates credentials
   └─ Reports success/failure

3. DATABASE CREATION
   ├─ Checks if database exists
   ├─ Creates if needed
   └─ Prepares for schema import

4. SCHEMA SETUP (Scripts run in order)
   ├─ Initial_ddl_Scripts.sql          ← Tables, constraints, relationships
   ├─ Initial_dml_Scripts.sql          ← Stored procedures, initial data
   ├─ V4_ddl_Scripts.sql               ← Schema updates
   ├─ V4_dml_Scripts.sql               ← V4 procedures
   ├─ Performance_Optimization.sql ⭐  ← Adds indexes, optimizes queries
   └─ PDF_Export_StoredProcedures.sql  ← PDF generation support

5. CONFIGURATION
   ├─ Updates App.config with actual SQL Server details
   ├─ Stores connection string with encryption
   └─ Ready for application use

┌─────────────────────────────────────────────────────────────────────────────────┐
│ COMMON ISSUES & SOLUTIONS                                                      │
└─────────────────────────────────────────────────────────────────────────────────┘

ISSUE: "Cannot connect to SQL Server"
  SOLUTION:
  ├─ Verify SQL Server is running
  ├─ Check instance name (use SQL Server Management Studio)
  └─ Verify credentials (username/password correct)

ISSUE: "Permission denied" during database creation
  SOLUTION:
  ├─ Use 'sa' account (has admin rights)
  ├─ Or: Grant 'CREATE DATABASE' permission to your user
  └─ Contact your DBA if uncertain

ISSUE: "Setup completed but application won't start"
  SOLUTION:
  ├─ Verify .NET Framework 4.8+ installed
  ├─ Check App.config connection string is valid
  └─ Review Event Viewer → Windows Logs → Application

ISSUE: "Family grid loading is slow"
  SOLUTION:
  ├─ Verify Performance_Optimization.sql executed successfully
  ├─ Check all indexes exist: SELECT * FROM sys.indexes WHERE name LIKE 'IX_%'
  └─ Contact support if indexes are missing
