┃ TROUBLESHOOTING QUICK FIXES                                               ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Problem: "Procedure 'sp_GetFamilyBasicDetailsForExport' not found"
Fix: 1. Run PDF_Export_StoredProcedures.sql
     2. Verify in SQL Server: sp_help sp_GetFamilyBasicDetailsForExport
     3. Restart application

Problem: "ModernPdfGenerator not found" (Compilation error)
Fix: 1. Copy ModernPdfGenerator.cs to project
     2. Add to project: Right-click → Add → Existing Item
     3. Rebuild: F6

Problem: Button doesn't appear on form
Fix: 1. Check panel name (should be 'rightFlow' or your panel)
     2. Verify button location has space
     3. Check button.Visible = true
     4. Adjust X position if overlapping other buttons

Problem: PDF is blank or has no data
Fix: 1. Check DataTable from procedure has rows
     2. Verify column names: FamilyID, FamilyName, etc. (case-sensitive)
     3. Test procedure directly in SQL Server

Problem: "Object reference not set" error
Fix: 1. Check if (dt != null && dt.Rows.Count > 0)
     2. Add null checks for each field
     3. Test with data that has all fields populated
